05 — offense to inform defense

Ethical hacking: problems solved

Challenges and internal engagements that pushed my security skills forward, sanitized for confidentiality where needed.

IDOR chain in a billing API

Found that sequential invoice IDs plus a missing ownership check let any account view another tenant's invoices. Reported and patched with row-level authorization.

Internal pentest · resolved

JWT algorithm confusion

A legacy service accepted "none" as a signing algorithm. Wrote a forged token as a proof of concept, then paired with the team to enforce strict algorithm allow-lists everywhere.

CTF-inspired · resolved

Race condition in coupon redemption

Parallel requests could redeem a single-use coupon multiple times. Fixed with a database-level unique constraint instead of an application-side check.

Bug bounty style · resolved
